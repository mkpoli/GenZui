GenZui Sans Okinawan {{VERSION}}
源萃ゴシック 沖縄文字

Regular and Bold. Install the TTF files for desktop use. The WOFF2 files and
included CSS provide the same fonts for websites.

This sentence-ready subset includes kana, punctuation, Latin, combining marks,
27 Funatsu Okinawan forms and eight prefectural raised katakana. Each face has
805 encoded characters. The character count includes encoded bases; voiced
forms use a base followed by combining dakuten U+3099. YI and YE use ordinary
い and え followed by that mark. Raised katakana have a half-em advance.

Private-use mappings require a compatible font and input method. The included
okinawan-mappings.json documents the text sequences and reference sources.
The editable index.html shows every form beside native kana in both weights.

The glyphs are GenZui drawings from Noto Sans JP. Both weights preserve the
native Sans stroke structure. See NOTICE.txt and OFL.txt for attribution and
licensing. This subset is distributed under SIL Open Font License 1.1.
