Raised katakana · 上付きカタカナ

The prefectural guide sets these as the text face’s katakana at about half size, top-aligned; GenZui derives them from Noto’s small kana. The reference column shows Xim Sans, the only other font found with these signs, or GenZui 0.114; the third column shows Noto’s small kana.

How Funatsu’s chart is set

Measured from the PDF itself: the body Mincho is 10.5 pt and the letters are set at the same size, 10.56 × 10.5, each on a one-em advance. So a letter occupies one full body-em square exactly like the kana beside it. Each pair below is the printed run from the chart and the same text set in GenZui at that em.
