# GenZui Serif 0.118

The ten Funatsu Okinawan ligatures TU, TI, KWA, KWI, KWE, HWA, HWI, HWE, WU
and TSI use Noto Serif JP stroke shapes, with revised connections, proportions
and terminals. Regular and Bold share these forms. Bold is composed from Noto’s native Bold strokes, with heavier source
weights for reduced vowels. Dakuten use the marks from native voiced kana.
SI retains native kana size, including its voiced form.

The release includes Noto-based glottal letters and SI, plus 181 Korean
gugyeol forms at the Hanyang private-use positions. Both weights contain
17,271 encoded characters.

Okinawan text uses the existing PUA assignments. Voiced forms remain a base
character followed by U+3099; the font composes them during shaping. Existing
documents and composer shortcuts require no conversion.

The package contains Regular and Bold TTF and WOFF2 fonts, an offline
specimen, the Windows installer, licences and validation reports. GenZui Serif
is distributed under SIL OFL 1.1.

GenZui Serif Okinawan / 源萃明朝 沖縄文字 is a smaller companion family for
kana sentences. Each weight contains 805 encoded characters: kana, Latin,
punctuation, combining marks, the 27 Funatsu forms and eight raised katakana
used in Okinawa Prefecture’s writing guide. The package includes an editable
sentence specimen and encoding mappings. Its outlines and spacing match the
full font. Kanji require the full family.
