GenZui Sans 0.105 adjusts stroke weight in the Okinawan forms and all 286 hentaigana.

Regular KWE/GWE and SI/ZI have lighter strokes. HWA/HWE’s vowel components have more weight, and Bold WA/WI/WE are stronger. The hentaigana use new Noto source instances calibrated against native Sans kana. Character coverage and input mappings remain the same.

- **GenZuiSans-0.105.zip**: full Regular/Bold family, 17,096 encoded characters, including kanji and historical kana.
- **GenZuiSansOkinawan-0.105.zip**: Regular/Bold subset, 805 encoded characters for kana sentences, punctuation, Latin and the 35 Okinawan forms.

Both packages include TTF, WOFF2, CSS, an editable specimen and licenses. Private-use characters need a compatible font; the mapping file is included. Distributed under SIL OFL 1.1.
