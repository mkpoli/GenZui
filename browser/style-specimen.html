Learning Serif → Sans

A paired CJK experiment for Tangut. Noto Serif supplies the input; the CJK target is the actual Noto Sans drawing. Tangut receives the same learned conversion.

Pilot · 2,048 training pairs · 256 validation pairs · 256 test characters · 78 stress forms + 2 donor controls · 140 Tangut samples

The learned shapes improve CJK overlap but round corners and alter small gaps. Tangut has no Sans target here; its drawings need visual and structural review.

Overlap is mean intersection-over-union. Boundary error is measured in a 1,000-unit em. Topology counts are a raster diagnostic for disconnected parts and enclosed white spaces; matching counts do not prove correct structure.

Method and limits
Serif ink + distance field→Spatial encoder→Sans-conditioned decoder→Distance field → traced outline

A 388,241-parameter convolutional encoder/decoder learns both conversion directions and identity reconstruction. Decoder features receive a Serif/Sans style code. One run softly penalizes differences between the paired bottleneck features; the other omits that term. Both use the same split, seed and 2,400-step budget. Each checkpoint is selected by validation overlap.

The representation has no explicit strokes or character labels. Skip connections can carry source style. A small difference between the two runs cannot establish that structure and style have separated.

Original fonts use their vector outlines. Learned SVGs trace the zero contour of a 256 × 256 predicted field (224 pixels per em). They have no fitted Bézier curves, stroke grammar or hinting. Fine contour noise and rounded terminals remain visible when enlarged.

CJK splits contain different code points; components recur across splits. The two donor controls, 一 and 丨, are excluded from the 78-form stress aggregate because the heuristic directly uses their Noto Sans outlines. Tangut is absent from training and checkpoint selection. One seed and one paired font family limit these results.

Font sources: Noto CJK · Noto Serif Tangut · Lorchin Sans 2.500. Lorchin is a comparison reference; exact upstream Tangut glyph revisions are unverified.

Architecture references: Ronneberger, Fischer & Brox, U-Net (2015); Perez et al., FiLM (2017). This pilot uses an independently implemented, smaller network.
